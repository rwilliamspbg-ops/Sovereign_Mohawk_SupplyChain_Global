# BETA_RELEASE

## Scope

This beta validates domain adaptation from ecosystem templates to supply-chain-specific federated learning workflows.

## Included

- Static geospatial supply-chain dashboard simulation.
- Policy-gated federated learning workflow placeholders.
- Initial supply-chain compliance evidence mapping.
- Baseline operator and governance documentation.

## Exit Criteria for GA Candidate

- Live telemetry integration for supply and compliance metrics.
- Region-policy enforcement tests for cross-border model flow.
- Security wrapper integration tests for signed update verification.
- Reproducible artifact capture and CI quality gates.
